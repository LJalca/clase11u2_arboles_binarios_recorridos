# Árboles Binarios y Recorridos Recursivos en Java — Sesión 11 (EDA)

**Asignatura:** Estructuras de Datos y Algoritmos (`CDS-0202`)  
**Carrera:** Carrera de Desarrollo de Software — ESPAM MFL  

## Contenido
- `src/NodoArbol.java`: Estructura de nodo binario en memoria (`dato`, `izquierdo`, `derecho`).
- `src/ArbolBinario.java`: Métodos recursivos `preorden`, `inorden`, `postorden`, conteo de nodos, hojas y altura.
- `src/Main.java`: Construcción del árbol ejemplo `[A, B, C, D, E, F, G]` y trazado limpio en consola.

## Compilación y Ejecución
```powershell
javac -encoding utf-8 -d bin src/*.java
java -Dfile.encoding=UTF-8 -cp bin Main
```
